# Черновик заявки ПФКИ · Федерация альпинизма России

Рабочие материалы для участия во **втором конкурсе ПФКИ 2027 года** (ПФКИ-27-2).

| Параметр | Значение |
|---|---|
| Приём заявок | до **7 декабря 2026**, 23:30 мск |
| Старт проекта (грант) | не ранее **1 июня 2027** |
| Окончание проекта | не позже **31 декабря 2028** |
| Макс. срок | 19 месяцев |
| Подача | только в ЛК: [фондкультурныхинициатив.рф](https://фондкультурныхинициатив.рф) |
| Заявитель (черновик) | ОООО «Федерация альпинизма России» |
| Контакт DPO | dpo@alpfederation.ru |

## Как пользоваться

1. Прочитайте стратегию и зафиксируйте решения по полям в квадратных скобках `[…]`.
2. Перенесите тексты из `01`–`03` в личный кабинет ПФКИ.
3. Замените все пометки `[ПОДТВЕРДИТЬ]`, `[ВСТАВИТЬ]`, `[УТОЧНИТЬ ЦИФРУ]` реальными данными.
4. Соберите презентацию PDF (10–15 слайдов) и письма партнёров.
5. Пройдите `04-cheklist.md` и подайте заявку **не позже 27 ноября 2026**, чтобы остался запас на доработку.

## Важно

ПФКИ прямо рекомендует не отдавать заявку «как есть» из генеративных моделей: тексты здесь — **черновик для вашей правки**. Эксперт читает конкретику, письма партнёров и связку «проблема → цель → задачи → мероприятия → цифры». Без ваших фактов, фото, КП и писем поддержки заявка не выдержит экспертизу.
