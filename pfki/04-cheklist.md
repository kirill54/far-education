# Чек-лист перед подачей заявки ПФКИ-27-2

Отмечать только после фактической проверки в ЛК.

## Сроки и формальные рамки

- [ ] Заявка будет отправлена **не позже 27.11.2026** (запас до 07.12.2026)
- [ ] В конкурсе у заявителя **только одна** заявка
- [ ] Старт проекта ≥ 01.06.2027, финиш ≤ 31.12.2028, срок ≤ 19 мес.
- [ ] Название без кавычек, точки, эмодзи, аббревиатурного мусора
- [ ] Устав (PDF) загружен; при необходимости — доверенность и скан подтверждения подачи

## Содержание «О проекте»

- [ ] Тип и тематическое направление осознанно выбраны и совпадают с текстами обоснования
- [ ] Ценности из Указа № 809 реально прослеживаются в концепции и мероприятиях
- [ ] Описание отвечает на: что / для кого / уникальность / ценности / территория / методы / результаты
- [ ] Презентация PDF 10–15 слайдов загружена (не текстовый «пересказ заявки»)
- [ ] Для образовательных продуктов приложено краткое содержание программ/методик
- [ ] География = только территории с письмами партнёров
- [ ] Целевая группа конкретная; у каждой группы есть мероприятия и результаты
- [ ] Актуальность подкреплена файлами (опрос, статистика, запросы), а не общими словами
- [ ] Цель одна, измеримая, достижимая к концу проекта
- [ ] Задачи ≥ 3, среди них есть информационное продвижение
- [ ] Количественные результаты сходятся с календарным планом
- [ ] Качественные результаты измеримы (тест, анкета, %, шкала)

## Команда и заявитель

- [ ] Руководитель и ключевые члены подтверждены в «Созидателях» (предпочтительно)
- [ ] Опыт команды соответствует масштабу (не «один человек на 7 млн»)
- [ ] Реквизиты заявителя, лицензия, опыт организации заполнены без противоречий

## Календарный план и бюджет

- [ ] У каждой задачи ≥ 2 мероприятий
- [ ] Нет расходов гранта до поступления средств на спецсчёт
- [ ] Суммы гранта/софина совпадают во всех полях
- [ ] На ключевые статьи есть КП / расчёты
- [ ] Софинансирование подтверждено письмами/справками
- [ ] Бюджет не выглядит как оплата коммерческого прайса ДПО

## Партнёры и коммуникация

- [ ] Письма партнёров — сканы с живой подписью/ЭЦП, без «фотошопа печатей»
- [ ] По каждому региону географии есть партнёр
- [ ] В письмах указан конкретный вклад и по возможности денежный эквивалент
- [ ] Каналы коммуникации названы конкретно; заложены обязательные упоминания ПФКИ

## Финальная вычитка

- [ ] Общедоступные поля (название, цель, задачи, география, суммы…) без опечаток
- [ ] Нет противоречий между разделами
- [ ] Все `[ВСТАВИТЬ]` / `[ПОДТВЕРДИТЬ]` из черновиков закрыты
- [ ] Тексты отредактированы «человеческим» языком команды (не оставлены как сырой ИИ-черновик)
