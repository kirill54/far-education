## Структура (два направления)

| Путь | Назначение |
|---|---|
| `index.html` | Хаб: выбор направления |
| `alpinizm/index.html` | Сайт «Альпинизм и горный туризм» |
| `ski/index.html` | Сайт «Ски-альпинизм и фрирайд» |
| `favicon.ico` | Фавикон как на alpfederation.ru |
| `*.docx` | Программы и проекты методик аттестации (скачивание) |

Пересборка треков из единого исходника (если правите общий каркас): `python split_sites.py`  
(скрипт ожидает «монолитный» `index.html` — после сплита хаб уже другой; для пересборки сначала восстановите монолит из git history).
