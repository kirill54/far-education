# Обучение и аттестация инструкторов-проводников ФАР

Живой сайт: https://edu.alpfederation.ru/

Репозиторий — исходник **публичного лендинга**. GitHub Pages (https://kirill54.github.io/far-education/) — старое демо, не боевой адрес.

Боевой раздел федерации на Битрикс: https://education.alpfederation.ru/ — этот макет туда ещё не перенесён целиком. Страница аттестации федерации: https://instructor.alpfederation.ru/

## Структура

| Путь | Назначение |
|---|---|
| `/` | Хаб: выбор «Обучение» / «Аттестация» |
| `/obuchenie/` | Лендинг обучения. В шапке два пункта: «Аттестация» и «Обучение» |
| `/attestaciya/` | Лендинг аттестации. Оба подвида (альпинизм / фрирайд) в первом экране |
| `/alpinizm/`, `/ski/` | Короткие редиректы на `/obuchenie/` |
| `/trenazher/` | Тренажёр теории. С лендинга аттестации ссылки на него нет |
| `*.docx` | Скачиваемые программы и методики |

Шапка обучения специально сведена к двум пунктам. Длинное якорное меню и бургер не возвращать, пока об этом не попросят.

## Генераторы

`rebuild_by_function.py` и `split_sites.py` — служебные скрипты пересборки страниц. После редиректов `alpinizm/index.html` и `ski/index.html` стали короткими; полный исходник при необходимости лежит в `sources/`.
