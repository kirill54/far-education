Репозиторий — исходник **публичного лендинга**.

- **Актуальная копия этого репозитория:** https://kirill54.github.io/far-education/
- **Боевой раздел федерации на Битрикс:** https://education.alpfederation.ru/
- **Страница аттестации федерации:** https://instructor.alpfederation.ru/

Адрес https://edu.alpfederation.ru/ (Yandex Cloud, `84.201.133.97`) на проверке 27.10.2026 (Europe/Moscow) не отвечает: DNS жив, HTTPS и HTTP таймаутятся. Поднять ВМ из этой среды нельзя.

Организационные PDF на Яндекс.Диске (раздел сведений) — 58 публичных файлов, все доступны.

Не публиковать на этом лендинге материалы письма 302/2.

## Структура

| Путь | Назначение |
|---|---|
| `/` | Хаб: выбор «Обучение» / «Аттестация» |
| `/obuchenie/` | Лендинг ДПО. Квалификация «по альпинизму и горному туризму» |
| `/attestaciya/` | Лендинг аттестации. Та же квалификация, включая ски-альпинизм и фрирайд; экзамен по ски/фрирайду — отдельно |
| `/alpinizm/`, `/ski/` | Короткие редиректы на `/obuchenie/` |
| `/trenazher/` | Тренажёр теории. С лендинга аттестации ссылки на него нет |
| `*.docx` | Скачиваемые программы и методики |

Шапка обучения специально сведена к двум пунктам. Длинное якорное меню и бургер не возвращать, пока об этом не попросят.
