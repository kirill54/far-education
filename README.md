# Готовая страница «Обучение инструкторов-проводников ФАР» + файлы для скачивания

Папка полностью самодостаточна и готова к выгрузке на сайт/хостинг.

## Состав папки
| Файл | Назначение |
|---|---|
| `index.html` | Готовая страница (чистый статический HTML: картинки встроены как data:URI, hover-эффекты переведены в CSS, зависимость от Claude Design убрана). Открывается двойным кликом. |
| `ДПП_профпереподготовка_инструктор-проводник_по_Приказу-266_256ч.docx` | Скачивание из карточки «Инструктор-проводник…» (ДПО, 256 ч) |
| `Программа_повышение_квалификации_72ч.docx` | Скачивание «Программа повышения квалификации (72 ч)» |
| `ДПП_повышение_квалификации_первая_помощь_72ч.docx` | Скачивание «Оказание первой помощи (72 ч)» |

## Что было сделано
- Исходный файл из Claude Design (`Обучение инструкторов-проводников ФАР.html`) был в формате
  «bundler» (страница упакована в JSON + JS-рантайм). Он **распакован в обычный HTML**, который
  работает на любом хостинге и в Битрикс24 без служебных скриптов.
- Ссылки на скачивание переведены с `.pdf` на **редактируемый `.docx`** — можно править в Word,
  потом при желании экспортировать в PDF и заменить файлы (имена оставить теми же — тогда ссылки на
  странице менять не придётся).

## Важно перед публикацией
1. **Ссылка «Копия лицензии (PDF)»** пока ведёт на `#` — подставьте реальный файл/URL скана лицензии.
2. Файл `Программа_повышение_квалификации_72ч.docx` сейчас заполнен нашей программой повышения
   квалификации (72 ч). Если для ДПО нужна отдельная редакция — замените файл, **сохранив имя**.
3. Ссылки в разделе «Сведения об образовательной организации» ведут на `/svedeniya/…` — это адреса
   боевого сайта; на демо-хостинге они будут работать только после публикации подраздела.
4. Если экспортируете `.docx` → PDF: положите PDF рядом и поменяйте расширения ссылок в `index.html`
   (`.docx` → `.pdf`), либо оставьте `.docx`.
