# Чек-лист интервью для отбора участников

**ЮГШ «Выше Облаков» — Актру 2027**

---

## Цели интервью (из обратной связи 2026)

1. **Честно проговорить условия:** суровый быт, тяжёлая дорога, серьёзные физнагрузки
2. **Отсеять совсем не готовых** → меньше проблем на смене
3. **Выявить сильных и опытных** → заранее черновые списки отделений

---

## Формат

- **Длительность:** 15–20 минут
- **Формат:** видеозвонок (Zoom/WhatsApp/Telegram)
- **Участники:** координатор + родитель + ребёнок
- **Когда:** до подписания договора

---

## Структура интервью

```
Добрый день! Меня зовут [Имя], я координатор Юношеской Горной Школы.
Это короткое знакомство, чтобы мы лучше поняли ожидания друг друга
и убедились, что программа подходит [Имя ребёнка].

Сначала несколько вопросов к [Имя ребёнка], потом к вам как к родителю.
Отвечайте честно — это в интересах всех.
```

### 4. Информирование об условиях (3 мин)

Обязательно проговорить:

```
Хочу честно рассказать о реальных условиях, чтобы не было сюрпризов:

📍 ДОРОГА
- 12–14 часов в автобусе в одну сторону
- Последние 10 км — на внедорожнике по бездорожью
- Может укачивать

🏔️ ВЫСОТА
- Лагерь на 2150 м, выходы до 3400 м
- Возможна горная болезнь (головная боль, тошнота)
- Физически тяжело, особенно первые дни

🏕️ БЫТ
- Проживание в модулях (не отель)
- Туалет общий, на улице
- Душ — по расписанию, вода может быть прохладной
- Интернет нестабильный или отсутствует
- Связь с родителями — ограниченная

⚠️ НАГРУЗКИ
- Пешие переходы 5–15 км в день
- Ночёвка в палатках на высоте
- Ранние подъёмы (4–6 утра на восхождение)
- Погода непредсказуема: дождь, снег, ветер

Всё это — часть программы и часть опыта. Если это вызывает сомнения — 
лучше обсудить сейчас, чем столкнуться на месте.
```

## Оценка кандидата

### Критерии оценки (1–5 баллов)

| Критерий | Баллы | Комментарий |
|----------|:-----:|-------------|
| Собственная мотивация ребёнка | | |
| Физическая подготовка | | |
| Опыт походов/лагерей | | |
| Самостоятельность | | |
| Коммуникабельность | | |
| Адекватность ожиданий (ребёнок) | | |
| Адекватность ожиданий (родитель) | | |
| Здоровье (нет противопоказаний) | | |
| **ИТОГО** | /40 | |

### Решение

- [ ] **Принят** (30+ баллов, нет красных флагов)
- [ ] **Принят с оговорками** (20–29 баллов, нужна подготовка)
- [ ] **Не принят** (<20 баллов или есть красные флаги)
- [ ] **Требуется повторный разговор**

### Красные флаги (отказ или серьёзное обсуждение)

- [ ] Ребёнок не хочет ехать, едет «потому что родители»
- [ ] Серьёзные хронические заболевания (астма, эпилепсия, диабет — индивидуально)
- [ ] Явная физическая неподготовленность без желания работать
- [ ] Родитель с завышенными ожиданиями («как в отеле»)
- [ ] История серьёзных конфликтов/буллинга
- [ ] Сильная зависимость от гаджетов без готовности отключиться

### Предварительное отделение

По результатам интервью можно предварительно отнести к:

- [ ] **Группа А** — опытные, сильные (первое восхождение, сложные маршруты)
- [ ] **Группа Б** — средний уровень (стандартная программа)
- [ ] **Группа В** — начинающие, нужна поддержка (облегчённая программа)
