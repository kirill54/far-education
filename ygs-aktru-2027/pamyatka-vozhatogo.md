# Памятка вожатого

**ЮГШ «Выше Облаков» — Актру 2027**

---

## Общие положения

Вожатый — ключевое звено между участниками, инструкторами и организаторами. Ваша задача — обеспечить безопасность, комфорт и позитивную атмосферу для детей.

**Возраст участников:** 14–18 лет  
**Количество участников:** до 30 человек  
**Соотношение:** 1 вожатый на 8–10 участников

---

## Зоны ответственности

### 1. Безопасность (приоритет №1)

- [ ] Знать местонахождение всех участников своей группы в любой момент
- [ ] Контролировать соблюдение правил безопасности
- [ ] Немедленно сообщать инструктору/руководителю о любых ЧП
- [ ] Знать расположение аптечки и медика
- [ ] Иметь при себе рацию во время выходов

### 2. Режим дня

- [ ] Будить участников вовремя
- [ ] Контролировать приход на приёмы пищи
- [ ] Обеспечивать отбой в установленное время
- [ ] Следить за соблюдением тихого часа (если есть)

### 3. Быт

- [ ] Контролировать чистоту в жилых модулях
- [ ] Организовывать дежурства
- [ ] Следить за сушкой вещей
- [ ] Помогать с бытовыми вопросами

### 4. Эмоциональное состояние

- [ ] Отслеживать настроение участников
- [ ] Выявлять конфликты на ранней стадии
- [ ] Поддерживать «отстающих» и интровертов
- [ ] Создавать позитивную атмосферу

### 5. Программа

- [ ] Проводить вечерние активности (игры, огоньки)
- [ ] Организовывать активности в автобусе
- [ ] Вести учёт баллов участников
- [ ] Помогать инструкторам на занятиях

## Взаимодействие с участниками

### Границы

**Можно:**
- Дружелюбное общение
- Совместные активности в рамках программы
- Поддержка и мотивация
- Обсуждение общих тем (горы, спорт, учёба)

**Нельзя:**
- Личные отношения за рамками «вожатый-участник»
- Обсуждение других участников/команды негативно
- Обещания, которые не можете выполнить
- Физический контакт (кроме помощи на маршруте)
- Общение в соцсетях во время смены (только после)

### Авторитет

- Будьте последовательны в требованиях
- Не делайте исключений «для любимчиков»
- Признавайте свои ошибки
- Держите слово

### Конфликты между участниками

1. Разведите конфликтующих
2. Выслушайте обе стороны отдельно
3. Не принимайте чью-то сторону публично
4. Помогите найти компромисс
5. При эскалации — сообщите руководителю

---

## Взаимодействие с инструкторами

- Инструктор отвечает за **техническую** безопасность на маршруте
- Вожатый отвечает за **организационную** часть (сбор группы, явка, состояние)
- Не спорьте с инструктором при детях
- Вопросы и предложения — наедине
- Поддерживайте авторитет инструктора

## Чрезвычайные ситуации

### Алгоритм действий

```
1. ОЦЕНИ ситуацию (есть ли угроза жизни?)
2. ОБЕСПЕЧЬ безопасность (убери из опасной зоны)
3. СООБЩИ руководителю/медику/инструктору
4. ДЕЙСТВУЙ по указаниям
5. УСПОКОЙ остальных участников
```

### Типичные ситуации

| Ситуация | Действия |
|----------|----------|
| Участник потерялся | Сообщить инструктору → организовать поиск → не паниковать |
| Травма на маршруте | Первая помощь → вызов медика → не перемещать при серьёзной травме |
| Конфликт с дракой | Разнять → развести → сообщить руководителю |
| Участнику плохо (горняшка) | Спуск ниже → вода → медик |
| Истерика/паника | Отвести в сторону → успокоить → дыхательные упражнения |
| Пропажа вещей | Не обвинять → общий сбор → сообщить руководителю |

## Вечерние активности

### Огоньки (темы по дням)

| День | Тема огонька | Формат |
|------|--------------|--------|
| 0 | Знакомство | «Кто я и зачем приехал в горы» — свеча по кругу |
| 4 | Страхи | «Чего я боюсь в горах» — откровенный разговор |
| 7 | Вершина | «Что я почувствовал на вершине» — обмен эмоциями |
| 10 | Благодарность | «Кому я благодарен за эту смену» — свеча |
| 11 | Прощание | «Что я увезу с собой» — финальный огонёк |

### Правила огонька

1. Говорит тот, у кого свеча/камень
2. Не перебивать
3. Не критиковать и не комментировать
4. Можно пропустить («передаю дальше»)
5. Всё сказанное — конфиденциально

### Игры для группы

**На знакомство:**
- Снежный ком
- Две правды и ложь
- Общие черты

**На сплочение:**
- Верёвочный курс
- Слепой квадрат
- Переправа

**На активность:**
- Квест по точкам
- Захват флага
- Ночной дозор

## Работа в автобусе

### Активности на трансфере (Блок 4.4)

| Этап пути | Активность | Материалы |
|-----------|------------|-----------|
| 0–2 часа | Игры на знакомство | Нет |
| 2–4 часа | Викторина «5 регионов» | Карточки |
| 4–6 часов | Видео о горах + обсуждение | Ноутбук/планшет |
| 6–8 часов | Входной квиз | Бланки |
| Перед прибытием | Правила и ожидания | Нет |

### Правила в автобусе

- Пристёгнутые ремни
- Не ходить во время движения
- Мусор — в пакеты
- Громкость музыки/разговоров — умеренная

## Чек-лист вожатого

### До смены

- [ ] Изучить программу смены
- [ ] Пройти инструктаж
- [ ] Получить памятку (этот документ)
- [ ] Познакомиться с командой
- [ ] Подготовить игры и материалы
- [ ] Проверить снаряжение
- [ ] Сохранить контакты экстренных служб

### В начале смены

- [ ] Познакомиться с участниками своей группы
- [ ] Узнать особенности здоровья (аллергии, хронические)
- [ ] Проверить наличие необходимого снаряжения у всех
- [ ] Объяснить правила и режим
- [ ] Создать чат группы (если разрешено)

### Ежедневно

- [ ] Утренний обход — все проснулись, самочувствие
- [ ] Проверка явки на приёмах пищи
- [ ] Контроль сушки вещей после выходов
- [ ] Вечерний обход — все на месте, отбой
- [ ] Обновление баллов участников
- [ ] Короткий отчёт руководителю

### В конце смены

- [ ] Сбор обратной связи от участников
- [ ] Проверка сбора вещей
- [ ] Передача контактов (если уместно)
- [ ] Отчёт руководителю

---

## Важные напоминания

> **Вы — пример для участников.** Если вы не соблюдаете правила, дети тоже не будут.

> **Безопасность важнее программы.** Лучше отменить активность, чем рисковать.

> **Не бойтесь просить помощи.** Вы часть команды, а не одиночка.

> **Документируйте инциденты.** Любой ЧП — письменно, сразу.

> **Берегите себя.** Уставший вожатый — плохой вожатый.
