## Что нужно подготовить до смены

### Материалы
- [ ] Библиотека презентаций (9 тем)
- [ ] Квизы к каждой лекции (распечатать)
- [ ] Фильмы скачать оффлайн
- [ ] Наклейки и карточки участников
- [ ] Мерч для обмена на баллы

### Оборудование
- [ ] Телескоп для астрономии
- [ ] Попкорн + инвентарь
- [ ] Проектор / ноутбук для киновечеров
- [ ] Гитара

### Согласования
- [ ] Темы лекций распределить между инструкторами
- [ ] Научный блок согласовать с ТГУ
- [ ] Водители автобуса — проверенные
