# Актру — учёт доходов, расходов и зарплат

Веб-сервис для базы **Актру** (кафе, столовая, склад, баня).

## Как устроено (по вашим правилам)

- **Оклад** — фиксированный, задаёт управляющий в карточке сотрудника.
- **Премия** — только от **продаж, которые сотрудник сам внёс** в систему; процент премии задаёт **руководство**, сотрудники его не меняют.
- **Сезон** — летние месяцы (май–сентябрь); в интерфейсе есть быстрый выбор «Летний сезон».
- **Несколько людей с доступом** — у каждого свой токен:
  - **staff** — вкладка «Продажи» и свой расчёт на «Зарплаты»;
  - **manager** — операции базы, обзор, все продажи, расчёт ФОТ;
  - **admin** — то же + выдача токенов на вкладке «Доступ».

Доход кафе в **журнале операций** (касса, закупы) ведёт управляющий. Это **баланс базы**. Продажи сотрудников — **отдельный журнал** только для премий; суммы можно сверять (в расчёте зарплат показываются обе цифры).

## Быстрый старт

```bash
cd aktru-uchet
cp .env.example .env
# Задайте ADMIN_TOKEN — мастер-токен администратора
npm install
npm start
```

1. Откройте http://localhost:3847, войдите с `ADMIN_TOKEN`.
2. Вкладка **Сотрудники** — создайте людей кафе: оклад и **% премии от своих продаж**.
3. Вкладка **Доступ** — создайте пользователей `staff`, привязав к `employee_id` из списка; передайте каждому **токен** (показывается один раз).
4. Сотрудники заходят со своим токеном и вносят продажи после смен.

### CLI: создать пользователя

```bash
node scripts/create-user.js --name "Иванова" --role staff --employee-id 1
node scripts/create-user.js --name "Директор" --role manager
```

## Роли

| Роль | Может |
|------|--------|
| staff | Вносить и удалять **свои** продажи; смотреть **свою** строку в расчёте зарплат |
| manager | Всё по базе: операции, баланс, все продажи, сотрудники, расчёт ФОТ |
| admin | + создание и отключение учётных записей |

## Формула зарплаты (кафе)

За период (например май–август):

- **Оклад** ≈ `оклад_месяц × (дней в периоде / 30)`
- **Премия** = `(сумма внесённых продаж сотрудника) × (% премии / 100)`
- **Итого** = оклад + премия

## Деплой

VPS, Node 20+, HTTPS, бэкап `data/aktru.db`. Токены хранятся как SHA-256 в БД; при утечке — деактивируйте пользователя и выдайте новый токен.
