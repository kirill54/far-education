# Актру — учёт доходов, расходов и зарплат

MVP веб-сервиса для базы **Актру** (кафе, столовая, склад, баня): журнал операций, баланс по подразделениям, расчёт ФОТ кафе с премией от оборота.

## Быстрый старт

```bash
cd aktru-uchet
cp .env.example .env
# Задайте ADMIN_TOKEN в .env
npm install
npm start
```

Откройте http://localhost:3847 — в шапке сохраните тот же токен, что в `.env` (нужен для добавления и удаления записей).

## Возможности MVP

| Раздел | Что делает |
|--------|------------|
| **Обзор** | Доход / расход / баланс по каждому подразделению и итого за выбранный период |
| **Операции** | Ввод дохода или расхода: дата, подразделение, категория, сумма, комментарий |
| **Зарплаты** | Выручка кафе за период → премиальный фонд (% настраивается) → делится между сотрудниками по полю «% от фонда» + пропорциональный оклад |
| **Сотрудники** | Справочник: ФИО, подразделение, оклад, доля премиального фонда |

Данные хранятся в SQLite (`data/aktru.db`). При первом запуске создаются подразделения и типовые категории.

## Логика премий (можно менять под ваши правила)

1. За период считается **выручка кафе** (все операции типа «доход» по подразделению «Кафе»).
2. **Премийный фонд** = выручка × `cafe_bonus_pool_pct` (по умолчанию 8%, настраивается на вкладке «Зарплаты»).
3. У каждого сотрудника кафе поле **«% от премиального фонда»** — доля фонда (сумма по всем активным сотрудникам обычно 100).
4. **Оклад** за период: `оклад_месяц × (дней в периоде / 30)`.

Если нужны другие схемы (фиксированный % от личного оборота, разные фонды для столовой/бани, сменные ставки) — это следующий этап после обкатки MVP на сезоне.

## Развёртывание на сервере

- Подойдёт любой VPS с Node 20+.
- Поставьте reverse proxy (nginx/Caddy) с HTTPS.
- Регулярный бэкап файла `data/aktru.db`.
- Для нескольких пользователей с разными ролями позже можно добавить полноценную авторизацию; сейчас один общий токен администратора.

## Дальнейшее развитие (по приоритету)

1. Экспорт в Excel / Google Sheets за месяц.
2. Отчёт «кассовая смена» — быстрый ввод выручки за день одной формой.
3. Склад: остатки номенклатуры (отдельный модуль).
4. Telegram-бот для внесения выручки с телефона без браузера.
5. Разделение прав: директор / управляющий кафе / бухгалтер.

Репозиторий `far-education` — сайт ФАР; этот каталог можно вынести в отдельный репозиторий или деплоить отдельным сервисом на поддомене (например `uchet.aktrucamp.ru`).
