# Актру — учёт доходов, расходов и зарплат

Веб-сервис для базы **Актру** (кафе, столовая, склад, баня).

## Как устроено (по вашим правилам)

- **Оклад** — фиксированный, задаёт управляющий в карточке сотрудника.
- **Премия** — только от **продаж, которые сотрудник сам внёс** в систему; процент премии задаёт **руководство**, сотрудники его не меняют.
- **Сезон** — летние месяцы (май–сентябрь); в интерфейсе есть быстрый выбор «Летний сезон».
- **Склад** — номенклатура и остатки; **списание** оформляет тот, кто взял товар (кафе, баня…); **приход** — управляющий. Система не даст списать больше, чем есть на остатке.
- **Вход** — email из списка администратора и код из письма. Роли: сотрудник, управляющий, администратор.

Доход кафе в **журнале операций** (касса, закупы) ведёт управляющий. Это **баланс базы**. Продажи сотрудников — **отдельный журнал** только для премий; суммы можно сверять (в расчёте зарплат показываются обе цифры).

## Быстрый старт

```bash
cd aktru-uchet
cp .env.example .env
# ADMIN_EMAIL — почта первого администратора
npm install
npm start
```

1. Откройте http://localhost:3847. Команда `npm start` только из папки `aktru-uchet`.
2. Введите email администратора. Пока в `.env` пустой `SMTP_HOST`, код входа показывается на странице и в логе сервера. С SMTP код уходит на почту.
3. **Сотрудники** — оклад и % премии. **Доступ** — email и роль. Чужой адрес код не получит.

Демо-цифры лета 2026: `npm run seed`.

### Роли

| Роль | Вход | Возможности |
|------|------|-------------|
| Сотрудник | email из списка | Продажи, списание со склада, своя зарплата |
| Управляющий | email из списка | Дашборд, операции, приход на склад, сотрудники, ФОТ |
| Администратор | email из списка | То же + список email, смена роли, включение и отключение доступа |

## Формула зарплаты (кафе)

За период (например май–август):

- **Оклад** ≈ `оклад_месяц × (дней в периоде / 30)`
- **Премия** = `(сумма внесённых продаж сотрудника) × (% премии / 100)`
- **Итого** = оклад + премия

## Деплой

VPS, Node 20+, HTTPS, бэкап `data/aktru.db`. Для писем задайте SMTP в `.env`. Отключить человека — кнопка «Отключить» на вкладке «Доступ».

## Склад

1. Управляющий добавляет позиции и оприходует поставки.
2. Склад открывается с **остатками**. Кнопки «Списание», «Приход», «Новая позиция» и «Журнал» открывают отдельные окна.
3. Таблица **Остатки** подсвечивает позиции ниже минимума (мин. задаётся при создании).
